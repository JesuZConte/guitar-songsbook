# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.4.x   | ✅        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private disclosure flow:
**Security → Advisories → Report a vulnerability**

We aim to respond within 7 days. Once the issue is confirmed and patched, we will publish the advisory so the community is informed.
